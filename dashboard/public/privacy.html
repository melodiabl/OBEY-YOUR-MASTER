Política de Privacidad

Última actualización: 18 de junio de 2026

Esta Política de Privacidad describe qué datos recopila OBEY (el "Bot"), cómo los usamos y tus opciones. Al añadir o usar el Bot en un servidor de Discord, aceptas esta política.

1. Datos que recopilamos

Recopilamos únicamente lo necesario para que el Bot funcione:

  • Datos de servidor: ID del servidor, IDs de canales y la configuración que defines (prefijo, idioma, canal de música, ajustes de sistemas como moderación, niveles, etc.).
  • Datos de usuario: tu ID de usuario de Discord, asociado a funciones que tú activas: canciones favoritas, playlists, historial/estadísticas de reproducción, economía, niveles y similares.
  • Datos de música: títulos, artistas y enlaces de las canciones que reproduces, favoritos y playlists que creas.
  • Presencia de voz (temporal): en qué canal de voz estás para poder reproducir música; no se almacena de forma permanente.
  • Panel web (opcional): si inicias sesión en el dashboard con Discord, usamos los permisos identify y guilds para mostrarte tus servidores. La sesión se guarda de forma segura.
No recopilamos el contenido de tus mensajes salvo el comando que invocas, ni contraseñas, ni datos de pago.

2. Cómo usamos los datos

  • Proveer las funciones del Bot (música, favoritos, playlists, configuración por servidor, estadísticas).
  • Recordar tus preferencias y las del servidor entre sesiones.
  • Mostrar rankings y "más reproducidas" del servidor.

No vendemos, alquilamos ni compartimos tus datos con terceros con fines comerciales.

3. Terceros

Para reproducir audio, el Bot consulta servicios de música (como Spotify, YouTube, SoundCloud o Apple Music) a través de Lavalink. Esas plataformas tienen sus propias políticas. El Bot funciona sobre la API de Discord, sujeta a la Política de Privacidad de Discord.

4. Almacenamiento y seguridad

Los datos se guardan en una base de datos MongoDB privada con acceso restringido. Aplicamos medidas razonables para protegerlos, aunque ningún sistema es 100% infalible.

5. Retención y eliminación

Conservamos los datos mientras uses el Bot. Puedes eliminar tus datos:

  • Quitando el Bot del servidor (se eliminan los datos de configuración de ese servidor).
  • Usando los comandos de borrado disponibles, o solicitándolo en nuestro servidor de soporte.

6. Tus derechos

Puedes solicitar acceso, corrección o eliminación de tus datos personales contactándonos en el servidor de soporte.

7. Menores

El Bot está destinado a usuarios que cumplen los Términos de Servicio de Discord respecto a la edad mínima. No recopilamos conscientemente datos de menores de esa edad.

8. Cambios

Podemos actualizar esta política. Los cambios se publican en esta misma página con su fecha. El uso continuado del Bot implica la aceptación de la versión vigente.

9. Contacto

Para cualquier duda sobre privacidad, contáctanos en nuestro servidor de soporte de Discord.
