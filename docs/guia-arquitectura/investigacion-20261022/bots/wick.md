Categoría: Seguridad. Evidencia: documentación. Nivel: profunda-documental. Consulta: 22/10/2026.

## Comprobado y alcance

La documentación describe Anti-Nuke, cuarentena, heat, lockdown y verificación. También reconoce que la configuración completa requiere tiempo.

Fuente primaria: [Wick](https://docs.wickbot.com/intro/features/). Para commits/archivos ver [código](../02_CODIGO_PUBLICO.md); para imágenes ver [referencias](../03_REFERENCIAS_VISUALES.md).

## Propuesta para OBEY

Modo observar antes de aplicar; explicar cada regla, registrar la causa y ofrecer recuperación controlada.

Módulos de destino: security,automod,verification. Conectar a sus servicios actuales antes de cambiar la presentación. El cambio debe conservar los datos y permisos del servidor. Implementar confirmación real, error recuperable, vacío y caducidad; no confirmar por haber editado un mensaje.

## Qué no queda demostrado

No trasladar sus afirmaciones comerciales de eficacia a OBEY ni activar sanciones por apariencia de cuenta. No se probaron flujos en una cuenta o servidor del proveedor. No se midieron popularidad, latencia ni disponibilidad.

## Cierre al implementar

Relacionar el requisito con una operación OBEY, su entrada Discord, traducción, material y caso de aceptación. Si se necesita una API ajena, comprobar contrato, permisos y licencia antes de activarla. Una página de documentación pública no concede acceso a datos internos del bot.
