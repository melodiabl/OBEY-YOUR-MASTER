# Mudae → OBEY

Categoría: Anime y colecciones. Evidencia: catálogo web. Nivel: comparativa-limitada. Consulta: 22/10/2026.

## Comprobado y alcance

Se comprobó el catálogo público con búsqueda y filtros de personajes. La wiki oficial apareció en búsqueda, pero sus páginas de comandos no se extrajeron de forma suficiente.

Fuente primaria: [Mudae](https://mudae.net/search?type=character). Para commits/archivos ver [código](../02_CODIGO_PUBLICO.md); para imágenes ver [referencias](../03_REFERENCIAS_VISUALES.md).

## Propuesta para OBEY

Colección original OBEY con filtros, favoritos, fichas y consulta web autorizada.

Módulos de destino: collections,profiles. Conectar a sus servicios actuales antes de cambiar la presentación. El cambio debe conservar los datos y permisos del servidor. Implementar confirmación real, error recuperable, vacío y caducidad; no confirmar por haber editado un mensaje.

## Qué no queda demostrado

No se verificó el flujo actual de rolls/claims ni capturas de sus mensajes. No copiar ilustraciones o base de personajes. No se probaron flujos en una cuenta o servidor del proveedor. No se midieron popularidad, latencia ni disponibilidad.

## Cierre al implementar

Relacionar el requisito con una operación OBEY, su entrada Discord, traducción, material y caso de aceptación. Si se necesita una API ajena, comprobar contrato, permisos y licencia antes de activarla. Una página de documentación pública no concede acceso a datos internos del bot.
