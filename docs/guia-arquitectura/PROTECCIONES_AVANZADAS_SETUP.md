# Protecciones avanzadas

Entrega local 56/63 comandos: antinuke y epicgamesverify. Antinuke mantiene las siete áreas, sus listas de roles/usuarios permitidos, límites día/semana/mes/total, acciones y los nombres de campos que consume el motor (incluido noeededalltimecount). Formularios nativos, selección exclusiva de usuarios, borrador/Save/CAS y paginación. Sin eval ni listeners globales añadidos por el menú.

Solo el propietario actual del servidor puede abrir/usar este editor. Se elimina el acceso especial al ID fijo del creador anterior. El perfil recomendado requiere selección explícita y Save; conserva listas, registro y cuarentena. El guardado no sanciona usuarios. La aplicación de cuarentena es una acción distinta: comprueba propiedad, sesión, rol y ManageRoles antes de cada overwrite; espera cada respuesta, conserva otros bits y omite canales ya aplicados. Puede quedar progreso parcial si falla Discord; repetir permite continuar. No se promete reversión automática de permisos.

El store de antinuke era un EnmapLike reiniciado al registrar eventos. Ahora la API legacy consulta su raíz antinuke del SyncMap/Guild existente; preferencias nuevas se guardan y los contadores por guild+miembro permanecen efímeros. Defaults completan campos ausentes sin reemplazar valores existentes. La inicialización del handler ya no descarta el store. No se crean colecciones ni se reescribe todo el motor de sanciones.

Epic mantiene canal, registro y custom ID original. Su verificador legacy no está incluido en coreHandlers: el menú lo declara y bloquea Publicar, con respuesta explícita de proveedor no activo. Permite guardar preferencias o retirar un panel vinculado. La API legacy consulta la raíz epicgames del Guild existente. No se activa el handler ni se afirma una verificación real del proveedor. Su integración/autenticación necesita trabajo aparte antes de habilitar publicaciones.

Siete grupos temporales Mongo/SDK: todos los builders/campos/páginas es/en, cambio de propietario antes del efecto, vista legacy y contadores sin filas persistentes, CAS/límites cero/aislamiento de raíces, perfil recomendado conservando listas, cuarentena idempotente/sesión expirada y bloqueo de Epic inactivo. Transporte Discord simulado, base propia eliminada. Regresión de soporte/publicaciones y 25 tests originales, tipos/dependencias y diff comprobados. Sin tests/scripts permanentes, login, llamadas de sanción reales, push o despliegue.
