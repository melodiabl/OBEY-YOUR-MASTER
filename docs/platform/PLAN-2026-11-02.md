## Decisiones vigentes

- Conservar landing, materiales, tipografía y recursos existentes. No regenerar gráficos ni publicar propuestas B. La documentación que menciona previsualizaciones no incluye esos HTML en este ZIP; no se consideran diseños aprobados.
- «Constructor / OBEY Builder» es el nombre de destino de Architect. Migrar consumidores y compatibilidad por recorrido; no renombrar comandos, datos ni rutas activas a ciegas.
- React/Next con la paleta actual para el panel interno. Mientras exista exportación estática, mantener la API y sesión actuales, sin Route Handlers dinámicos ni segunda autoridad de permisos.
- Fastify/TypeScript es una evaluación posterior con paridad de seguridad. `DECISION_WEB.md` y los planes 09–12 conservan Express durante P1; la lista general de dependencias no obliga a sustituirlo antes de estabilizar música.
- Un solo motor musical y una sola cola. El usuario eligió su fork NyxLink el 03/11: sustituye el objetivo previo `lavalink-client`. La implementación usa `nyxlink@0.1.0-dev.2` con Player/Queue nativos y retira Shoukaku. La aceptación operativa de P1 sigue abierta; véase [la migración](NYXLINK-MIGRATION.md).
- Los 32 módulos son alcance planificado, no 32 servicios terminados. Colecciones, eventos, destacados y verificación requieren confirmar dominio y datos antes de prometer nuevas funciones. No crear carpetas vacías para simular la migración.
