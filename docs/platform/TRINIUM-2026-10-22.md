# Revisión de Trinium · 22/10/2026

La [web indicada por el usuario](https://lavalink.triniumhost.com/) publica su configuración mediante [API del operador](https://lavalink-api-status.triniumhost.indevs.in/config/nodes). Se verificaron las tres opciones HTTPS publicadas desde el host del bot, sin usar token de Discord, iniciar voz ni cambiar producción. Los dos endpoints HTTP publicados quedan fuera de la selección.

| Nodo | Resultado observado |
| --- | --- |
| Lavalink Java TLS | `/v4/info` devuelve HTTP 502; no se acreditó versión o funcionamiento actual |
| NodeLink 01 | API v4 y WebSocket disponibles, mediana 143 ms en cinco ping/pong; Spotify devuelve una pista, YouTube/SoundCloud agotan 9 s; letras y audio para la pista Spotify disponibles |
| NodeLink 02 / canary | API v4 y WebSocket disponibles; medianas 142,6 y 145,3 ms en dos rondas de cinco ping/pong; seis búsquedas de YouTube/Spotify/SoundCloud con resultados; dos pistas devuelven letras y audio PCM |

NodeLink 02 entregó 193.648 y 192.424 bytes PCM con muestras no nulas. Una consulta adicional con volumen cero devolvió 192.016 bytes, todos cero. Los datos de audio se descartaron en memoria; no se guardaron audio, encodings ni letras. Los tiempos son de control desde este servidor, sin demostrar ping de voz, capacidad bajo carga o continuidad durante horas.

De estas tres opciones, NodeLink 02 es el candidato que mejor respondió en esta muestra. Su motor declara 3.8.0 y acepta API `/v4`; la versión del software no es la versión del protocolo. [Contratos oficiales de NodeLink](https://nodelink.js.org/docs/api/rest).

OBEY todavía necesita adaptación para sus letras nativas `/v4/loadlyrics`; la ruta actual combina LavaLyrics y LRClib. La caché de capacidades actual también descarta software cuyo major no sea 4. La muestra no acredita todos los filtros/plugins o reproducción Discord. Los resultados actuales mejoran la muestra del 17/10; no sustituyen el límite documentado de pruebas concretas.

No se habilitó Trinium ni se cambió el principal/respaldo. Bot saludable, cero reinicios y nodo privado apagado. Los dos verificadores y la captura temporal de configuración pública se eliminaron tras guardar [evidencia agregada](evidence/trinium-review-20261022.json). No hubo mensajes ni eventos reales de prueba o push.
